# CS-330
Projects and artifacts for CS-330: Computer Graphic Design at SNHU.
Design Decisions: 3D Scene Development

3D Object Representation and Complexity
I made a simulation of a high-fidelity 3D environment for this project while modeling the 2D reference image using low-polygon primitive shapes. I aimed to showcase a sophisticated representation of objects by constructing intricate models from multiple meshes. As an example, I designed the fireplace mantel as a complex object with four distinct primitives: two tapered cylinders, a box for the top ledge, and a standard cylinder for the base trim. By mirroring the tapered cylinders, I created a sharp "V-shape" architectural peak in the center of the mantel. This choice was intentional, as it allows the wood material to catch specular highlights more effectively than a flat box. I encapsulated that logic in a custom function, making sure my code remained modular and reusable. This helped me adjust the assembly scale and position with a single function call, adhering to industry-standard best practices for efficiency.

Sophisticated Texturing Techniques
To go beyond the conventional texture requirements, I implemented a multi-texturing scheme on the rug through the addition of 2 texture units (using the same source image at different sampling frequencies). This provided the advanced “self-overlay” effect that greatly amplified the perceived texel density and surface details with barely any new texture file memory needed. Binding the primary rug pattern to GL_TEXTURE0 and a high-frequency version of the same image to GL_TEXTURE1, I simulated a realistic woven fabric appearance, avoiding the "blurred" appearance commonly seen in stretched single textures. At the end, I calibrated the UV scale for a high density to make sure that the large pattern size reflected the physical scale of the room in a smooth, professional way, and the finish felt so professional. This way, I show how I can do a multi-texture thing in one shader with a stronger effect without wasting too much memory and making it very complex and low yielding. Also, I implemented a sophisticated self-overlay technique for the curtains by blending two instances of the fabric texture at different UV sampling frequencies. This simulated vertical pleats and micro-wrinkles, enhancing the realism of the cloth material without requiring additional assets.

Advanced Lighting and Phong Shading
I adapted the lighting strategy by employing the full Phong shading model, consisting of Ambient, Diffuse, and Specular elements for a 'Polished Presentation'. I designed a global directional light to achieve a neutral room ambiance and a specific, colored point light placed inside the fireplace to meet the rubric’s requirement for varied light sources. I applied a warm orange touch to the point light to imitate the glow of embers. And to avoid overly saturating the room, I added attenuation logic to the fragment shader. This mathematical “fade-out” provides that the light is intense near the fireplace but naturally fades off once it makes it to the far walls. Additionally, a spotlight was included in the ceiling to generate targeted downward light and show I'm able to do 3 types of light (Directional, Point, Spot) with one rendering pipeline.

Navigation and User Interaction
I designed the camera navigation to be intuitive while providing nuanced control over the 3D space. I implemented a traditional WASD system for horizontal and depth movement, but I also added vertical navigation using the Q and E keys to allow the user to explore the scene from different heights. To exceed expectations in camera control, I linked the mouse scroll wheel to a dynamic speed variable. This allows the user to precisely moderate the speed of movement at runtime, facilitating a more controlled exploration of the detailed models. Finally, I implemented a real-time projection toggle. By tapping the 'P' or 'O' keys, the user can instantly switch the viewport between a Perspective (3D) and Orthographic (2D) display. This functionality was achieved by dynamically switching the projection matrix in the render loop, ensuring the user can analyze the spatial layout of the objects from both a realistic and a schematic viewpoint.

Modular Code and Complex Hardware Design
To ensure my project adhered to professional "Best Practices," I focused on the logical encapsulation of my code through the development of modular, custom functions. My most significant development in this area was the implementation of a specialized transformation and rendering pipeline for complex assemblies. By creating a standardized method for handling multi-part objects, such as the architectural curtain rods, I was able to maintain clean code while building intricate structures. These rods are a prime example of sophisticated 3D representation; rather than using a single floating cylinder, I constructed a "U-wrap" return system using three interlocking cylinders and decorative spherical ball joints.
The primary challenge was ensuring these components were perfectly connected without spatial gaps. I programmed this functionality by utilizing precise coordinate snapping, where the horizontal bars and wall-return rods intersect at exact integer coordinates. By placing the spherical joints at these intersection points, I hid the mesh seams and created a unified, structural look. This modular approach allowed me to duplicate the entire assembly for both windows simply by shifting the X-anchor, demonstrating how reusable code can significantly reduce development time while increasing the visual complexity of a scene.
Furthermore, I organized my program by separating the Asset Management (textures and materials) from the Scene Logic. By centralizing all texture loading into a single initialization function, I was able to efficiently manage the GPU’s texture units. This organization was crucial for the "multi-texture" effects on my rug and curtains, as it ensured that the correct IDs were always available to the shader units. This level of modularity not only made my program functional but also easily extensible, allowing me to add new high-fidelity objects without cluttering the main render loop.
